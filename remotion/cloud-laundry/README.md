# 云朵洗衣店 · Cloud Laundry
Original30s Remotion2D film. Painted attic background, continuous procedural cloud-to-linen metamorphosis, original score and foley.
## Run
npm ci
npm run typecheck
npm test
npm run studio
node scripts/render.mjs --stills
node scripts/render.mjs
## Environment
Dependencies pinned to Remotion4.0.534/React19.0.4. Current cloud sandbox allows npm and bundling but prevents Chromium Unix socket creation. Render via authorized Actions. REMOTION_LOOPBACK_ONLY=1 optionally supplies a loopback-only host configuration when interface enumeration is unavailable; does not change system settings. Browser path override BROWSER_EXECUTABLE.
## Assets
attic-background.jpg generated for this production; no third-party artwork copied. Original music synthesized by accompanying audio/synthesize.py. Input authorizations and creative records maintained in user's Notion animation log.
## Verification limits
Motion tests establish deterministic finite geometry and anchors, not aesthetic quality. Review rendered dense samples at squeeze, watering, attachment and scene boundaries. Do not claim realtime playback unless actually performed.
