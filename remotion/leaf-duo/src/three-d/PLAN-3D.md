# 一叶入梦 / Remotion 原生 Three 15s

规格：1920×1080、60 fps、900 帧。入口 Leaf3D.tsx；宿主 Root 统一挂独立原创配乐 three-d.wav。镜头不是旧版本4镜头的迁移，所有运动为 frame/fps 的纯函数，禁止 useFrame / wall clock / Math.random。

## 原生3D证据
- @remotion/three ThreeCanvas，真实透视相机、索引曲面叶片、DoubleSide meshStandardMaterial，曲面与叶脉共享 leafPoint；顶点季节配色，冬叶霜边。
- 真场景几何：32块石料月门、独立玻璃/梁柱、树干分枝、620实例叶冠、花/睡莲/盆栽/灯/雪台；非CSS立方体、非旧视频叠帧。
- 风、叶尖柔动、飘尘、相机全部由 useCurrentFrame()/fps 驱动；任意seek一致。
- 关键帧90/300/540/780在**主叶 mesh.onAfterRender**读取WebGL context，输出LEAF3D_WEBGL日志与window.__LEAF_3D_EVIDENCE。不是仅凭 state 自证渲染。
- 资源清理：逐帧叶曲面、叶脉和粒子几何释放旧资源；几何实例用于远景植被，减少调用。
