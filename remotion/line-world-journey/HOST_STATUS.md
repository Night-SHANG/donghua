# Line World Journey Remotion host

New multi-scene film using original code-authored projected 3D/SVG scenes. This is not a 3D humanoid-rig workflow. No AI-generated imagery or reference-video assets are used.

Local preparation only until permission and creative source freeze. Duration/composition are owned by the director. Render host will never silently stretch or pad the scene to match a guessed duration.

Pipeline: pinned Remotion 4.0.534; actual codec preflight before browser; one half-resolution preview with native keyframes; independent review; final native resolution from unchanged creative source. Source, audio generator and timing are frozen by SHA-256. Final CI compares all project files to approved preview commit except render-plan.json. Film verification includes frame count, dimensions, H264/AAC, exact duration, zero stream start times, decoded audio loudness and true peak. Full local null decode is repeated after download.

Host tests and source compilation do not establish artistic quality, pacing, or motion fluency. Actual Remotion artifacts will be labeled as such only after successful cloud rendering. No local Chromium sandbox bypass is attempted.
