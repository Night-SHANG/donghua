## 视觉与角色
暖色水彩/纸张纹理、细墨轮廓、南欧石板坡道与小面包店。保持概念的轮廓、主色、表情和可爱感；不是逐像素复刻生成图的毛发与水彩细节。

团团：灰棕浣熊、黑眼罩、奶油脸、大头短腿、青绿围裙、分节环尾。正面/四分之三/侧面/后四分之三/背面均有真实绘制轮廓、遮挡和五官规则。背面不留正面眼睛；跑跳有脚掌支撑、身体压缩伸展、尾巴拖随。

啾脚：栗棕麻雀、奶油胸、小喙、细腿、过大的折纸厨师帽。翅膀始终是翅膀，不变成人手；拉围裙靠喙，搬篮靠喙牵篮柄、扑翼与小跳辅助。转向有不同头身与翼层次，不能靠概念图贴图平移冒充动作。帽子落后于头部转动，遮眼时保留喜剧可读性。

配角默认简洁兔阿姨，仅结尾反应，不新增支线。无对白，靠表情、动作和轻巧配乐/拟音叙事；不用生成图上的中文标题作为字体资产。

## 八镜头（具体秒数为执行默认，可在约60秒内小幅调节）
| 时间 | 镜头 | 叙事与动作验收 |
|---|---|---|
| 0–7 | 店门前建立 | 团团把最后一个面包包上烘焙纸；啾脚搬篮，明确空间关系 |
| 7–13 | 事故 | 大帽滑落遮眼，啾脚撞篮，包好的面包滚出；因果清楚 |
| 13–23 | 下坡追赶 | 团团追、伸爪扑空并急停，啾脚随后赶上；重心、步幅与落脚可信 |
| 23–30 | 希望落空 | 面包暂卡台阶，双方松口气，纸包又滚；暂停有表演而非冻结 |
| 30–36 | 发现办法 | 团团看见斜木板，视线由面包转向木板，再与啾脚交换眼神 |
| 36–45 | 合作准备 | 团团展开围裙，啾脚用喙拉另一边；接触点和布料受力清楚 |
| 45–53 | 高潮 | 面包沿板飞起，落进围裙，两者共同承住；不凭空瞬移、不穿布 |
| 53–60 | 回店回扣 | 返回店前，兔阿姨已看完整场；刚得意，帽子再滑，两者反应收尾 |

## 先做的5秒动作验证
取追赶镜头的 `16–21s`，剪成独立 `0–5s`：追跑进入→蓄力伸爪→面包擦过扑空→前脚支撑急停/尾巴跟随→啾脚跟上并停住。120帧，不是五张关键帧幻灯片。
先看姿态联系表与连贯视频；轮廓像、动作有重量、脚不滑、表情看得懂、帽子/尾巴不乱抖才进入整片。用户先审短段；技术通过不能替代视觉批准。

## 不变的技术/权限边界
- p5 2.3.3 + p5.brush 2.2.3 + 已成功的安全 GitHub Actions runner；复用 core/timeline，不换引擎，不新造通用 IK。
- 1920×1080、24fps；全片默认60秒/1440帧，短段5秒/120帧；H.264 yuv420p BT.709 + AAC stereo 48kHz。
- 原案例入口、源码与原渲染流程保持可用；新片独立入口和命名空间。
- Chrome 保留 sandbox；不得用 --no-sandbox、权限扩大、禁用安全限制或 native 绕过云浏览器 WebGL2 禁用。
- 免费标准 runner；显式安装并预检 ffmpeg/ffprobe；先测时再分段，不付费、不加 secret、不改权限。
- 时间求值必须纯函数、可乱序渲染；动作、道具和声音共用命名事件，不依赖逐帧累积。
- 静态可缓存，但不能把角色冻结、让线条随机种子错位或抹掉水彩风格；边界 SSIM 仅诊断，不是审美/叙事验收。
- 当前仅在 /tmp 独立 worktree 保存设计与计划，不 push、不上传、不触发 Actions、不使用用户本地电脑。之后远端操作必须另按 donghua 的实际授权执行，不能套用 chache 的长期授权。

## 风险与完成定义
主要风险是角色从概念到程序绘制的落差、双角色/围裙接触与重心、长片的水彩绘制计算量，以及音画喜剧节奏。短段优先暴露这些风险；没有时长/费用保证。
