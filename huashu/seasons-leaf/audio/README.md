# 四季之叶：原创连续配乐

15.000秒，48kHz双声道24-bit PCM。原创E大调五声音阶乐句，柔软钢琴模态、稀疏玻璃泛音和合成自然风声。全段统一脉动、音符尾音重叠、和声层交叠；四季不是四个分别起止的小片段。

- 3.75 / 7.50 / 11.25秒是视觉转场中心，轻风起伏从前0.55秒渐入，跨界持续，不作强撞击重音。
- 春夏秋冬用和声与泛音密度的渐变连接，音乐不随剪辑硬停。
- 14.2秒开始0.8秒余韵收束；15秒精确为零，无截断咔哒声。

生成：`python audio/synthesize.py`。测试：`python audio/test_audio.py`。依赖Python、numpy、scipy、ffmpeg；不访问网络，不用外部音源、模型、样本或已有旋律。

CI应以master.wav做最终视频音轨；music.m4a仅为方便单独检查的压缩版本。music-only.wav / foley-only.wav为调音分轨。

实测master为-20.01 LUFS、-7.57dBTP。编码、波形、转场无静音间隙和重复生成已检查；未主观试听，不将客观检查当作听感验收。
