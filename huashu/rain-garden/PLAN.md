# 雨滴里的小花园 — 15秒原生短片
无人物、无文字、无图像切割。暖金/青绿的原创微缩水生花园。

1. 0–3.8s：微距荷叶，露珠沿叶脉聚向尖端；2.8s脱离，重力下降，3.8s触水。
2. 3.8–7s：同位置圆形匹配接水面，涟漪外扩；4.05s回弹小水珠，所有圆环以同一撞击点为中心。
3. 7–11s：波纹到达花茎，引发7.2/8.3/9.4s三簇睡莲依次绽放，粒子从花心升起。
4. 11–15s：同世界相机拉远揭示悬浮苔藓岛，远处星点与近景叶产生视差，14–15s呼吸收尾。

原生工具：PAINT.cached/noise/fbm/grain、U.rng、CAM.at/with；水面横向短笔触与外扩椭圆参照官方scenes/28_monet.js，但不复制人物和原场景。完全原创程序绘画，无新增外部资产。各镜同一个world(globalTime)连续运动，ERAS仅负责分镜注册，不重置状态；避免接镜时植物或水滴传送。

动作和摄影不是运动指标填充：露珠→撞击→涟漪→绽放→空间揭晓构成因果链。调色、纹理均固定种子，无满屏随机闪动。

验收必须逐帧覆盖2.75–4.3、6.9–7.4、10.9–11.3秒。静态测试不等于视觉通过，成片需实际密集帧审。
