# 《雨滴里的小花园》原创15秒配乐

## 构建与接入

在项目根目录运行：

```sh
python audio/synthesize.py
python audio/test_audio.py
```

需要 Python 3、numpy、scipy、ffmpeg/ffprobe。脚本不联网，不使用采样包、外部曲谱、角色配音或付费服务。CI只需提交脚本、测试和本说明；WAV/编码版本由源码生成。

最终混音：`audio/master.wav`，恰好15.000秒、48 kHz双声道、24-bit PCM。优先将它与影片复用，不要先从AAC再转码。`music.m4a`仅为便于独立审听的192kbps AAC；另有音乐/音效分轨。

## 配乐设计

原创D大调/B小调五声音阶小品，非循环警示音。软钢琴以衰减弦模态和短锤击噪声合成，玻璃泛音轻点高处；低音和扩展和弦托住温暖空间，小幅立体声与稀疏早期反射提供景深。动作留白后再回应，14–15秒为余韵，而非突然截断。

| 时间 | 同步内容 |
|---|---|
| 0–3.8 | 露珠：稀疏软钢琴与轻空气感 |
| 2.8 | 脱离叶尖：很轻的气流，不做夸张滑音 |
| 3.8 | 触水：水滴主音准确起于触点 |
| 4.05 | 小水珠回弹：更轻、更短的水音 |
| 3.8–7 | 涟漪：低和声延展，水面轻噪尾 |
| 7.2 / 8.3 / 9.4 | 三簇花依次展开，递进的轻玻璃泛音 |
| 11–15 | 同世界拉远，和声回到D调 |
| 12.2 | 浮岛小星河揭示的柔和高音 |
| 14–15 | 余韵淡出到严格零端点 |

## 实测与边界

- PCM混音实测 -20.00 LUFS，真峰 -6.52 dBTP；不经过动态响度压缩，只按首次测量施加常量增益。
- 15.000秒/720000采样，H.264合成时建议AAC 192kbps。
- 6项自动检查覆盖时长、PCM类型、端点、直流偏移、峰值/响度、镜点列表、途中非静音、声道相关性及WAV/AAC完整解码。
- 两个独立Python进程重建的4个音频文件SHA256一致，见REPRODUCIBILITY.txt。
- 检查是波形和编码层面的验证，**未宣称主观试听通过**；艺术效果最终以整片播放为准。

输出文件由脚本生成，`audio-cues.json`保存完整音符及同步点，`build-result.json`保存实测响度和SHA256。
