# 风叶蒙太奇 — 原创15秒动作配乐

源音全部为原创程序合成：阻尼钢琴模态、玻璃泛音、带限噪声风阵及触雪声。无录音样本、外部乐谱、付费API或外部音频授权依赖。

## 结构
- 0–3.6秒春：枝头轻颤的短音；0.6秒后上卷升音与强风；1.25秒后停止新音，保留自然尾音表现滞空；2.1秒翻面轻风。
- 3.6–7.2秒夏：低空掠水的短促跳音与侧摆气流，6.6秒抬升准备切镜。
- 7.2–11秒秋：较强阵风与升音后向下翻滚音型，9.2秒后稀疏失速，避免持续匀速琶音。
- 11–15秒冬：风声渐薄、旋律下降，14.2秒细雪接触与自然尾音。

精确镜点为3.6/7.2/11.0秒。配乐有动态呼吸，但不在切点硬静音。起止波形为零，最后0.8秒收尾。

## 重建
在项目目录运行 `python audio/synthesize.py && python audio/test_audio.py`。
依赖：Python、NumPy、SciPy、FFmpeg；与现有CI音频依赖一致。

输出 `master.wav` 为15秒、48000Hz、双声道、24位PCM；同时生成music-only.wav、foley-only.wav和AAC试听编码。CI只需提交synthesize.py、test_audio.py、audio-cues.json、README.md，音频可完整重建。

## 实际验证
- 主混音输入实测 -20.00 LUFS、-2.83 dBTP（build-result.json 的 input_i/input_tp 是实际输出文件测量，非loudnorm模拟输出字段）。
- 8项测试：PCM规格、时长、峰值、端点、响度、cue时点、切镜无硬静音、相位与解码，并独立确认阵风段foley能量大于滞空/失速段两倍。
- 两次独立进程生成的PCM主混音、两stem及AAC SHA256一致。
- 仅波形／编码／时点与测量验证，未主观试听，不代表音乐审美已验收。
