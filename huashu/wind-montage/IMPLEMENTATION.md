# 风带一叶 · 原生三维四镜实现

- 15 秒 / 60 fps / 1920×1080。原生 huashu SCENES → Three r160 WebGL 离屏 1280×720 → Canvas，非 Remotion，不以 2D 后备冒充 3D。
- 四个独立 Scene 与 PerspectiveCamera；3.6 / 7.2 / 11 秒明确硬切。春枝头近景、夏低水位、秋仰拍林冠、冬雪地远景；不共用场景换色。硬切保留动作方向动机，未声称已经实现遮挡擦镜或严格像素动作匹配。
- 分段风事件驱动：春短蓄势后上升、滞空、下降并翻面；夏贴水侧摆上扬；秋上升停滞后下降并滚转 2.35π；冬摇摆下落、触地轻弹。摄像机独立缓移，不完美追踪叶中心。
- 单张连接的 861 顶点叶片，叶脉跟随同一个曲面；每季颜色、粗糙度、卷曲、霜边变化。场景统一物理材质和光照，真透视、深度测试与投影。
- 音频由独立音频子任务维护，见 audio/ 下说明与自测。

## 验证边界
本地 Node 使用同一 Three 库投影 901 个状态样本：有限数、可见中心、四镜头状态、镜内步长、明显纵向位移和屏幕轨迹、春翻面与秋完整翻滚通过。screen/projectedSize 是状态的几何投影，不是视频像素识别；仍须 GitHub 原生渲染验证 WebGL、观察切镜前后画面、叶片完整性、阴影和水面关系并审阅真实运动。数值通过不等同艺术效果优秀，不声称视频已渲染或已视觉验收。
