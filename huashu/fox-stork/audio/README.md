# 原创音乐与细小拟音

这条音轨为本片65秒/14镜新写，不使用配音、对白、外部采样、现成音乐或付费媒体API。

## 集成

- `master.wav`：完整音乐＋拟音，48kHz立体声PCM24，严格3,120,000帧 / 65秒。视频混音优先使用它。
- `music.m4a`：**同一完整混音**的AAC压缩版，不是纯音乐。不要与master叠放。
- `music-only.wav`、`foley-only.wav`：供细调的分轨，同长度、同起点、同增益；两轨相加回到完整混音（PCM量化误差除外）。
- `audio-cues.json`：所有音符、音效、全片秒点、各镜边界、静默段、实测响度/峰值、文件hash。
- `QA.txt` 与 `*.ebur128.txt`：真实技术测量，不是试听或最终音画同步已通过的声明。

```sh
python audio/synthesize.py
python audio/test_audio.py
python audio/audit_onsets.py
```

仅依赖Python、NumPy、SciPy、ffmpeg/ffprobe；无需soundfile或下载音源。
CI的`audioBuild`可设为两个argv数组：`["python","audio/synthesize.py"]`、`["python","audio/test_audio.py"]`。
合成采用固定随机种子20261028；固定依赖/编码器版本可复建。
AAC容器标记65.000秒；裸解码有AAC的128样本末端填充，需严格帧数时使用WAV。

## 声音设计

F大调、96 BPM的轻室内乐动机：A–C–D–C–A。第一餐以短拨弦与温暖低拨弦为主；回请段把同一身份转给气息轻的木管与竖琴式拨弦。第二餐并不做胜利号角；尾声把动机向下收回，给耳朵和眼神让位。

弦音由独立衰减的谐振模式、短起音、少量木质噪声构成；木管使用非纯正弦的谐波、微小颤音和滤波气息。陶器为短非整数比共振；液体为细滤波摩擦加微小气泡；碰口只是一点柔和闷响，不是撞伤。角色无服装，名为`cloth`的合成器只作为非常轻的羽毛/毛发或干接触摩擦纹理。

12.1秒干喙触盘后、45.1秒宽口鼻受阻后、50.3秒空舌回收后均不叠笑声音效。17秒眼神、60.1秒礼貌手势也让音乐停下来。最后63.5–65秒不再发起音乐或动作声，保留读表情的空间。

整个混音只作统一线性增益，目标约−20LUFS，不靠高响度/压缩掩盖表演停顿。母带和AAC分别实际测量真峰/响度；不用代码目标值冒充结果。

## 参考边界

已读huashu原生`references/05-节奏与配乐.md`、工作流审计及`scripts/audio/synth_艺术史速通.py`。只借鉴确定性合成、等功率声像、小空间混响、K加权/四倍真峰测量的技术思路。没有复用该15秒示例的乐谱、时代顺序、固定音效秒点或成品音频。本片所有音乐与拟音都以本片镜头表重新编排。

技术测试不能取代实际播放审听；最终视频还需要正常速度检视声音与接触帧是否一致。

`onset-audit.json`从真实PCM分轨检测互不重叠拟音的起音，按原生参考的3帧容许窗口检查，尖锐接触另用10ms更严格检查。它不替代最终画面接触检查，也不声称验证了重叠拟音的独立起音。
